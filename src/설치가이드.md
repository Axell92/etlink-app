# 현장 관리 앱 — 설치 가이드 (약 5분)

필요한 것: Google 계정 하나. 사용자들은 아무 계정도 필요 없음.

## 1. 스프레드시트 만들기 (측정기 223대 미리 들어있음)
1. https://drive.google.com → **새로 만들기 → 파일 업로드** → `현장관리DB.xlsx` 업로드
2. 업로드된 파일 우클릭 → **연결 앱 → Google Sheets** 로 열기
3. 열린 시트에서 **파일 → Google Sheets로 저장** (xlsx가 아니라 진짜 구글 시트가 되어야 함. 제목 옆에 .XLSX 표시가 없어지면 OK)
   - `instruments` 시트에 2022년 이후 교정 이력이 있는 185대만 들어가 있음 (그 이전·교정기록 없음 38대는 제외) (교정만료일 = 최종교정일 + 주기 로 계산해둠)
   - `sites`, `people`은 비어 있음 — 앱에서 추가

## 2. Apps Script 열기
1. 시트 상단 메뉴 **확장 프로그램 → Apps Script** 클릭
2. 왼쪽에 `Code.gs` 파일이 보임. 내용을 전부 지우고 **Code.gs** 파일 내용을 붙여넣기
3. 왼쪽 "파일" 옆 **+** → **HTML** → 이름을 `Index` 로 입력 (대소문자 정확히, `.html`은 자동으로 붙음)
4. 생긴 `Index.html` 내용을 전부 지우고 **Index.html** 파일 내용을 붙여넣기
5. Ctrl+S 저장

## 3. 배포 (링크 만들기)
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정:
   - 설명: 아무거나
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**  ← 중요 (로그인 없이 쓰려면)
4. **배포** → 권한 승인 창이 뜨면 본인 계정 선택 → "고급" → "…(안전하지 않음)으로 이동" → 허용
   (본인이 만든 스크립트라 구글이 경고만 띄우는 것. 정상)
5. 나오는 **웹 앱 URL** 복사 → 이게 앱 링크. 카톡으로 뿌리면 끝.

## 4. 휴대폰에 설치 (사용자 안내용)
- **아이폰**: Safari로 링크 열기 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 링크 열기 → 메뉴(⋮) → **홈 화면에 추가**
- 처음 저장 시 "편집자 이름"을 한 번 입력 (기기에 기억됨, 수정 기록에 남음)

## 데이터 확인
- `sites / people / instruments / log` 4개 시트가 DB
- 측정기를 대량으로 추가/수정할 땐 `instruments` 시트에서 직접 편집해도 됨 (`id` 열은 비워두면 안 됨 — 새 행은 앱에서 "+ 신규 등록"으로 넣는 게 안전)
- `log` 시트에 누가·언제·무엇을 추가/수정/삭제했는지 쌓임
- 시트를 직접 편집해도 앱에 반영됨 (단 `id` 열은 건드리지 말 것)

## 나중에 앱을 수정할 때
1. Apps Script에서 `Index.html` 또는 `Code.gs` 내용 교체 → 저장
2. **배포 → 배포 관리 → 연필(수정) → 버전: "새 버전" → 배포**
   - 이걸 안 하면 수정이 링크에 반영되지 않음. 링크 자체는 그대로 유지됨.

## 자주 묻는 것
- 링크 열었는데 "권한 필요"가 뜬다 → 3-3의 액세스 권한이 "모든 사용자"가 아님. 배포 관리에서 수정.
- 느리다 → Apps Script 특성상 저장에 1~2초 걸림. 정상.
- 링크를 아는 사람은 누구나 수정 가능 → 회사 내부 공유용으로만. 외부 유출 주의.

## (추가) 2026-11-06 검토 후 변경
### Code.gs 교체 (배포 관리 → 연필 → 새 버전 → 배포)
- 저장 순서 보장, 시트에 직접 붙여넣은 행의 id 자동 부여, 현장 삭제 속도 개선
- GAS 웹 링크(/exec)는 이제 "앱 열기" 안내 페이지만 보여줌. Apps Script 안의 Index.html 파일은 더 이상 안 쓰므로 지워도 됨
### 접속 코드(PIN) 켜기 — 선택
1. Apps Script 편집기 왼쪽 톱니(프로젝트 설정) → 아래 **스크립트 속성** → "스크립트 속성 추가"
2. 속성: `PIN` / 값: 원하는 숫자(예: 4~6자리) → 저장
3. 그 순간부터 앱 사용자는 처음 한 번 접속 코드를 입력해야 함(기기에 저장됨). 끄려면 속성 삭제.
### 확인할 것
- Apps Script 프로젝트 설정 → **시간대**가 `Asia/Seoul`인지 (아니면 시트에 날짜 서식으로 입력된 값이 하루 어긋날 수 있음)
- 백업: 구글 시트 파일 → 버전 기록(모든 수정 되돌리기 가능). 분기마다 "파일 → 사본 만들기" 권장
